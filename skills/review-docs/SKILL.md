# Review Docs

문서를 **코드와 1:1 대조**해 틀린 곳을 찾는다. 문장을 다듬는 작업이 아니라 사실을 검증하는 작업이다.

## 절차

1. 문서에서 검증 가능한 주장(명령어, 경로, 옵션명, 시그니처, 기본값, 버전)을 전부 뽑는다.
2. 각 주장을 코드/설정 파일에서 확인한다. 확인 수단이 없으면 "미검증"으로 분류한다.
3. 명령어와 코드 예제는 실제로 실행한다.
4. 결과를 표로 보고한다.

| 위치 | 문서의 주장 | 실제 | 판정 |
|---|---|---|---|
| `README.md:12` | `--port` 기본 8080 | 코드 기본 3000 | 오류 |

## 판정 기준

- **오류** — 코드와 명백히 다름. 근거 `file:line` 필수.
- **낡음** — 과거엔 맞았으나 현재 코드에 없음.
- **누락** — 공개 API/필수 설정인데 문서에 없음.
- **미검증** — 확인 수단이 없음. 추측으로 오류 판정하지 않는다.

수정은 사용자가 요청할 때만 한다. 기본은 지적까지다.
