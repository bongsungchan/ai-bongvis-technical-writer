---
description: 커밋 범위로부터 릴리즈 노트를 작성한다
argument-hint: [git 범위, 예: v1.2.0..HEAD]
---

`$ARGUMENTS` 범위(비어 있으면 마지막 태그부터 HEAD)의 커밋과 diff를 읽고 릴리즈 노트를 작성한다.

1. `git log --oneline` 과 `git diff --stat` 으로 범위를 파악한다.
2. 커밋 메시지를 그대로 옮기지 말고, **사용자에게 보이는 변화**로 다시 쓴다. 내부 리팩터링만 있는 커밋은 묶어서 한 줄로 처리한다.
3. `### Breaking` / `### Added` / `### Fixed` 순으로 묶고, 각 항목에 관련 PR·이슈 번호가 있으면 붙인다.
4. Breaking change는 마이그레이션 방법을 한 줄로 함께 적는다.
5. 커밋에서 확인되지 않는 내용은 넣지 않는다. 판단이 애매한 항목은 목록 아래에 "확인 필요"로 따로 표시한다.
